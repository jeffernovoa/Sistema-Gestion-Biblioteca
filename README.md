# Sistema-Gestion-Biblioteca
https://github.com/jeffernovoa/Sistema-Gestion-Biblioteca.git

📚 **Sistema de Gestión de Biblioteca**

Este es un proyecto de gestión de biblioteca implementado en Python, que simula un sistema de préstamo y devolución de libros. El sistema incluye la gestión de libros, usuarios y empleados, permitiendo funcionalidades como:

+ Registro de usuarios y libros.
+ Consultas sobre la disponibilidad de libros.
+ Préstamos y devoluciones de libros.
+ Persistencia de datos utilizando archivos .pkl para mantener el estado de la biblioteca entre sesiones.

***Características:***
- Interfaz gráfica: Utiliza Gradio para ofrecer una interfaz fácil de usar, donde los empleados pueden registrar libros y usuarios, y los usuarios pueden realizar préstamos y devoluciones.
- Persistencia de datos: Utiliza pickle para guardar y cargar el estado de la biblioteca (usuarios y libros) entre ejecuciones del programa.
- Estructura modular: El código está organizado en múltiples archivos para mejorar la legibilidad y facilidad de mantenimiento.

***Tecnologías Utilizadas:***
- Python: Lenguaje de programación principal.
- Gradio: Para la interfaz de usuario.
- pickle: Para guardar y cargar el estado de la biblioteca.
